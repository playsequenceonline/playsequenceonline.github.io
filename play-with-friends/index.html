How to play Sequence online with friends in 4 steps

One person hosts. They start a room and share the link. Everyone else opens the link, types a name and joins. The host starts the game.

  1. Start a room. Open Chipline, tap Play with friends, type your name and tap Start a new room. You are now the host.
  2. Share the invite link. Tap Share or Copy and send the link to your friends on WhatsApp, Messenger or any chat. If you are on a call, you can read out the 5-letter room code instead.
  3. Friends join. Each friend taps the link, types a name and taps Join the game. Their name appears in the room for everyone.
  4. Start the game. The host picks the teams and a turn timer, then taps Start game. The server deals the cards, and each player only ever sees their own hand.

New to the game? Read the rules of Sequence, explained simply. Chipline also lights up every space your card can use, so new players learn as they go.

How many players and teams

Chipline takes 2 to 12 players. The game starts with 2, 3, 4, 6, 8, 9, 10 or 12 people so the teams come out even. Seats alternate between teams, so teammates never play back to back.

Host settings: turn timer and computer players

Before the game starts, the host can shuffle or reorder the seats, choose 2 or 3 teams, set a turn timer, and add computer players to any empty seat.

  • Turn timer: 30, 60 or 90 seconds a turn, or no timer for a relaxed game. 60 seconds is the default.
  • Computer players: tap Add computer player to fill an empty seat. You can remove it any time before the game starts.
  • Play again: when a game ends, the host can start a rematch with the same room, or go back to the lobby to change teams.

If someone drops out or the internet cuts

The game keeps going. If a turn runs out of time, the computer plays it. If someone leaves mid-game, a computer takes their seat.

  • Miss two turns in a row and the computer keeps playing for you until you tap I'm back.
  • Lost your connection? Open Chipline again on the same phone and you return to your seat.
  • Closed the tab by accident? Rejoin with the same room code while the room is still open.

Tips for an online game night

  • Talk while you play. Start a WhatsApp, Zoom or Google Meet call, and keep Chipline open in the browser on the same phone or on a second device.
  • Pick the timer for your group. 30 seconds keeps a big group moving; no timer suits family games with younger or newer players.
  • No peeking, no hints. Teammates may not say which cards they hold or where to play. Table talk is part of the fun, but card talk is not.
  • Mix in a practice round. New players can try a quick solo game against the computer first, from the home screen.
  • Same room? If everyone is at one table with one phone, choose Pass one phone around instead.

Questions about playing online with friends

How do I play Sequence online with friends?

Open Chipline, tap Play with friends, then Start a new room. Send the invite link on WhatsApp or any chat app. Each friend opens the link on their own phone, types a name and taps Join the game. When everyone is in, the host taps Start game.

Is it free to play online with friends?

Yes. Chipline is free for everyone in the room. Nobody needs to download an app or make an account, and only the host needs to start the room.

How many people can play together online?

From 2 to 12 players. The game starts with 2, 3, 4, 6, 8, 9, 10 or 12 players, so everyone fits evenly into 2 or 3 teams. If you are one short, the host can add a computer player to fill the seat.

Do all players need the same kind of phone?

No. Chipline runs in the web browser, so iPhones, Android phones, tablets and computers can all play in the same room.

Can friends join with a code instead of a link?

Yes. Every room has a 5-letter code. A friend can open Chipline, tap Play with friends and type the code under Got a code from a friend?

What happens if someone's internet drops?

Open Chipline again on the same phone and you go straight back to your seat. While you are away, the turn timer runs and the computer plays your turn for you so the game does not stall.

Can we play while on a video call?

Yes. Many groups play on a WhatsApp, Zoom or Google Meet call so they can talk while they play. Teammates still should not tell each other which cards they hold.

Can I play with friends at the same table on one phone?

Yes. Choose Pass one phone around instead. Each player takes their turn and passes the phone, and the screen hides the hand between turns.
